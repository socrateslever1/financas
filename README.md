# Open Minha Finanças

Reconstrução web acadêmica do aplicativo Minhas Finanças, com frontend Vite e API Cloudflare Pages Functions + D1.

> Estado: protótipo funcional em desenvolvimento. Não representa equivalência completa com o APK original.

## Execução

```bash
npm install
npm run dev
```

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Root: `/`
- Binding D1: `DB`

Não exponha chaves ou dados financeiros pessoais no repositório. Configure segredos pelo painel do Cloudflare.
